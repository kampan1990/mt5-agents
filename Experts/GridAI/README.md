# GridAI — AI-signal ATR Grid + VWAP basket TP (MT5)

## ติดตั้ง
1. คัดลอกโฟลเดอร์ `GridAI` ไปที่ `MQL5/Experts/` แล้ว Compile `GridAI.mq5` ใน MetaEditor
2. MT5 → Tools → Options → Expert Advisors → ติ๊ก **Allow WebRequest** แล้วเพิ่ม `https://api.anthropic.com`
3. ใส่ `InpApiKey` (อย่าแชร์ .set ที่มี key) — ต้องเป็นบัญชี **Hedging**
4. ผูกกับกราฟ XAUUSD (หรือสัญลักษณ์อื่น) ใช้ได้ทีละ 1 กราฟต่อ magic

## Logic
| ส่วน | พฤติกรรม |
|---|---|
| สัญญาณ | ทุก 300 วิ ส่ง M5 20 แท่ง + ATR ให้ AI → BUY/SELL (ไม่มี HOLD) ข้ามถ้ามีกริดค้างอยู่ (ไม่เสียค่า API) |
| ตัวกรอง 4 ข้อ | confidence ≥ 70% / อยู่ในเวลาเทรด / ยังไม่ชนลิมิตรายวัน / ไม่ใช่ศุกร์ ≥16:00 และเสาร์-อาทิตย์ |
| ไม้แรก | 0.01 lot ตามทิศ AI |
| ไม้ถัดไป | ราคาสวน 1 ระยะ ATR (ล็อกค่า ณ ไม้แรก) → lot ตาม `InpLotSequence` (0.01, 0.01, 0.01, 0.02 …) เกินลำดับ ×`InpLotMultiplier` |
| TP | VWAP ของทุกไม้ ± 100 points ตั้งเป็น TP ของ **ทุกไม้** (ปิดพร้อมกันฝั่งโบรกเกอร์) และอัปเดตทุกครั้งที่เพิ่มไม้ |
| เวลา (server) | 00–21 เปิดกริดใหม่ได้ · ศุกร์หยุดเปิดกริดใหม่ 16:00 · ส-อา ไม่เปิด · กริดเดิมยังรอ TP/เพิ่มไม้ได้ |
| เป้ากำไร | P/L วัน ≥ 20,000 → ปิดทุกไม้ แล้วหยุดทั้งวัน |
| ลิมิตขาดทุน | P/L วัน ≤ −9,995 → ปิดทุกไม้ แล้วหยุดทั้งวัน |
| จำนวนไม้ | `InpMaxGridOrders = 0` = ไม่จำกัด |

P/L รายวัน = deals ที่ปิดแล้ววันนี้ + floating (เวลาเซิร์ฟเวอร์ 00:00) คำนวณจากประวัติ จึงไม่รีเซ็ตเมื่อรีสตาร์ท EA

## ⚠️ ความเสี่ยง
- กลยุทธ์นี้ **ไม่มี SL ต่อไม้** (ไม้ละ TP แต่ไม่มี SL) ตัวป้องกันหลักคือลิมิตขาดทุนรายวัน ซึ่งเป็น **software** — ถ้า EA/เน็ต/VPS หลุด หรือตลาด gap ผ่านลิมิต จะไม่มีอะไรหยุด
- แนะนำตั้ง `InpEmergencySLPoints` เป็น SL กันหายนะฝั่งโบรกเกอร์ และทดสอบบน demo ก่อน
- lot เพิ่มตามลำดับ + ไม่จำกัดจำนวนไม้ = margin โตเร็วเมื่อตลาดวิ่งทางเดียว (มีเช็ค `InpMinMarginLevel` ก่อนเพิ่มไม้)
- Strategy Tester ใช้ WebRequest ไม่ได้ → EA ใช้สัญญาณสำรอง (momentum) แทน AI เพื่อทดสอบกลไกกริด/ลิมิต ผล backtest จึงไม่สะท้อนความสามารถของ AI
- 100 points บน XAUUSD (2 หลัก) = 1.00 USD — ตรวจ digits ของโบรกเกอร์
